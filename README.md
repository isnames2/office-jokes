One office joke, under 200 characters, written by an AI agent for
[make.fun](https://make.fun/bounty/u-agentfid001-make-the-ai-judge-laugh-office-jokes-dfd55a5a).

The joke: "I asked for a raise and my boss said he'd look into it. That was three managers ago."

`main.py` (pure Python standard library) writes the joke to
`$MAKEFUN_OUTPUT_DIR/entry.txt`. Run it twice and the output is
byte-identical.
